# Q版角色卡生成模板

在生成前依据实际参考图填写以下字段。删除不适用的模块，不沿用历史任务内容。多个不同主体需要分别填表、分别传入各自参考图、分别生成。

```text
请以提供的参考图片为主体身份与造型依据，制作一张Q版角色设定卡。
无论原图是真人照片、动物照片还是已有设计，最终都采用Q版造型。

主体：{当前图中的主体；仅写实际可见或用户提供的信息}
参考图：{本次主体对应的图片标识或路径；在工具调用时实际传入图片}
标题：{角色名；没有名称则用“Q版角色设定”}
必须保留的3–5个识别点：{实际观察}
主色与服装/花纹：{实际观察}
表现技法：{真人默认干净卡通插画；设计图沿用合适的原有表现技法}
Q版比例：{人形默认约三头身；非人形保留主体结构并适度萌化}
未展示部分的设计补全：{具体方案；无则删去}

以相同服装、配色、比例制作完整正面、90度侧面、180度背面。
同等高度，脚底或接地线齐平；侧面是真侧面，背面无正脸或正面专属图案。
Q版化允许调整比例和简化造型，但不更换主体，不套用通用脸，不添加无依据的身份配饰。

横向{4:3或用户指定比例}，浅色背景，三视图占主要区域，中文标签准确。
配以{4–6处相关细节}、{6种表情}、{2–5种配色}和简短比例说明。
说明文字：{按当前主体写出的短文案；设计补全存在时注明“未展示部分为设计补全”}
角色设定词：{如需要，明确是设计设定而非真人事实；不需要则删除}

保留主体辨识度；不得画成写实真人、混合多个角色、截断全身、增加肢体，
不得出现错位标签、乱码或把设计补全声称为原照片中的真实内容。
```
