# Q版角色卡 · Chibi Character Card

把真人照片、动物照片或已有角色设计，制作成保留主体辨识度的 **Q版角色设定卡**。

**输入决定“是谁”，技能负责将其转成Q版。** 真人照片也会卡通化；已有设计保留主要造型、配色和表现技法，再调整为Q版比例。

## 可以做什么

| 输入 | 输出 |
| --- | --- |
| 真人头像或半身照 | 保留发型、五官特点和可见服装的Q版人物卡 |
| 动物照片 | 保留物种特征与身体结构的Q版角色卡 |
| 插画、Logo或角色设计 | 沿用识别点与配色的Q版设计卡 |
| 已有Q版吉祥物 | 补充一致的三视图、细节和表情 |
| 多个主体，要求分别制作 | 每个主体一张独立角色卡 |

默认卡片包含正面、侧面、背面三视图，6种表情，4–6处细节，以及配色与比例参考。人形默认约三头身，横向4:3画幅，中文标注。

动物表情会先转成眼睑、视线、嘴部、耳位等具体动作，再生成和检查；保留物种结构与角色特征，避免六个标签对应同一张脸。详见 [动物表情规则](references/animal-expressions.md)。

照片中没有展示的身体、下装或背面可以做设计补全，并在交付时说明。若要求照片原貌不变，则不适用这套Q版转换流程。

## 使用前提

运行技能的助手需要能够查看参考图片，并调用支持参考图输入的图像生成或编辑工具。这个仓库提供技能说明与提示词模板，不是独立出图程序。

没有出图能力时，技能会提供填写好的提示词与设定文案，并说明尚未生成图片。

## 安装到 Codex

把本仓库放到技能目录，并保持文件夹名为 `chibi-character-card`：

```sh
mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
git clone https://github.com/Eileenes/chibi-character-card.git \
  "${CODEX_HOME:-$HOME/.codex}/skills/chibi-character-card"
```

也可以下载仓库ZIP，解压后将包含 `SKILL.md` 的文件夹命名为 `chibi-character-card`，放入同一技能目录。私有仓库的访问需要对应账号权限。

## 调用示例

上传参考图后，明确调用技能：

```text
请使用 $chibi-character-card，把这张照片制作成Q版角色卡。
保留发型、五官特点和原有服装，包含三视图、六种表情、细节和配色。
```

已有角色设计：

```text
使用 $chibi-character-card，把这个角色设计改成约三头身的Q版角色卡。
沿用原来的颜色、服装和线条风格，不添加新的配饰。
```

分别处理多张照片：

```text
使用 $chibi-character-card，为这两张照片中的人物各做一张Q版角色卡。
每人单独生成，保留各自的外貌和服装，不合成到同一张卡里。
```

可以补充角色名、用途、服装、比例、画幅或语言。没有名字时使用通用标题，不会自行给真人命名或推断职业、性格。

## 输出检查

- 主体的发型、五官、服装或动物特征仍有辨识度。
- 三视图属于同一角色，比例、服装与配色统一，身体完整。
- 表情和细节图与主视图一致，中文标签清楚。
- 遮住文字与装饰符号后，表情仍能区分；不以复制脸、换标签或轻微偏转凑满六格。
- 未展示部分注明设计补全，不把推演视图当成真实照片。

最终质量取决于参考图与所用图像工具。角色卡属于设计参考，不保证具有三维建模所需的尺寸精度，也不自动产生可编辑矢量文件。
